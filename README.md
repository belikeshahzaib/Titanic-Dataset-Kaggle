# Titanic Dataset — Kaggle

This repository contains my solution for the **Titanic-MTH3302_A26** Kaggle competition.

The project focuses on building a machine learning model to predict whether a passenger survived the Titanic disaster.

## Kaggle Competition

**Competition:** Titanic-MTH3302_A26
**Platform:** Kaggle

[View the Kaggle Competition](https://www.kaggle.com/competitions/titanic-mth-3302-a-26/submissions)

### `randomForest.ipynb`

Jupyter Notebook containing the machine learning workflow, including data preparation, model training, predictions, and evaluation.

### `submissionRF.csv`

The final prediction file generated by the Random Forest model and submitted to Kaggle.

## Machine Learning Approach

The project follows a typical supervised machine learning workflow:

1. Load and inspect the Titanic dataset.
2. Perform data preprocessing.
3. Prepare the features and target variable.
4. Train a Random Forest classification model.
5. Generate predictions for the test data.
6. Create the Kaggle submission file.
7. Submit the predictions to Kaggle.

## Model

**Random Forest Classifier**

Random Forest combines multiple decision trees to make predictions. It is useful for classification problems because it can capture nonlinear relationships between features and is generally more robust than relying on a single decision tree.
